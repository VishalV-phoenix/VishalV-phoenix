## 🚀 Featured Projects

### 1. LLM System Design

**Exploring the building blocks behind LLM-powered applications.**

A Python-based learning project focused on understanding how an LLM application can combine conversation memory, document retrieval, embeddings, and tool calling.

**What I've explored**
- Retrieval-Augmented Generation (RAG) for querying information from documents.
- PDF ingestion, text chunking, and embedding-based retrieval.
- Different retrieval approaches, including keyword, line-based, sliding-window, and embedding-based retrieval.
- Conversation memory and persistent vector-store experimentation.
- Model tool calling and integration with the Model Context Protocol (MCP).

**Technologies:** Python · LLM APIs · Embeddings · RAG · MCP · PyPDF

🔗 [View Repository](https://github.com/VishalV-phoenix/LLM-System-Design)

### 2. AlgoQuest

**Learn, visualize, and explore algorithms interactively.**

A Flutter-based application designed to make algorithm concepts easier to understand through visualizations, complexity graphs, code implementations, and algorithm comparisons.

**What it includes**
- Visual exploration of searching and sorting algorithms.
- Time-complexity graphs and experimental performance comparisons.
- Code views for Python and C implementations.
- Side-by-side comparison of algorithm behavior.

**Algorithms explored:** Linear Search · Binary Search · Bubble Sort · Selection Sort

**Technologies:** Flutter · Dart · Algorithm Visualization · Data Structures & Algorithms

🔗 [Explore AlgoQuest on GitHub](https://github.com/VishalV-phoenix/algorithm-playground)
